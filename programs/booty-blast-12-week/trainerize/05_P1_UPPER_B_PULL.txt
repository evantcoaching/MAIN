UPPER BODY SCULPT B
Pull Priority - Phase 1 (Weeks 2 & 4)
Width • Detail • Density

SESSION TYPE
Hypertrophy • Density • Control

FOCUS
Upper Back Width
Lats
Shoulder Pop
Rear Delts
Triceps
Strong backs build strong physiques. Every pull should create shape, not just move weight.

TEMPO STRUCTURE
Every working set follows:
Lower → Bottom Pause → Lift → Top Pause
Default Tempo: 3-1-2-1

OBJECTIVE
Prioritise vertical pulling to maximise lat width (the V-taper that makes the waist look smaller) while building upper back detail and capped shoulders.

WARM UP
• Band Pull Apart x15
• Straight Arm Pulldown x12
• Face Pull x12

BLOCK A | PRIMARY COMPOUND PULL ★ PR LIFT (Week 4)
A1. Neutral Grip Pull Up or Assisted Pull Up
3 x 6-8 (last set to FAIL)
Tempo 3-1-2-1
Rest 2 min
Cue
Pull elbows into your back pockets.
Drive the chest toward the bar.

BLOCK B | UPPER BACK DENSITY
B1. Chest Supported T Bar Row
2 x 8-10
Rest 90 sec
Cue
Drive elbows low.
Pause against the pad.

B2. Half Kneeling Single Arm Lat Pulldown
2 x 10-12/arm
Rest 60 sec
Cue
Reach long at the top.
Pull elbow toward your hip.

BLOCK C | SHOULDER WIDTH
C1. Cable Lateral Raise (behind body)
2 x 10-12
Tempo 2-1-2-1

C2. Dumbbell Lateral Raise
2 x 10-12
↓ Drop weight
C3. Top Half Partials
x10-15 reps
Rest 90 sec
Cue
Lead with the elbow.
Keep constant tension.

BLOCK D | REAR DELT DETAIL
D1. Reverse Pec Deck Single Arm
2 x 12-15/arm
Rest 45 sec
Cue
Open through the elbows.
Don't shrug.

BLOCK E | TRICEPS SS
E1. Overhead Rope Extension
2 x 12-15
↓
E2. Cross Body Cable Extension
2 x 12-15/arm
Rest 75 sec

BLOCK F | ABS
F1. Hanging Knee Raise
2 x technical failure
Rest 45 sec
Cue
Curl the pelvis up, don't swing.

COOL DOWN
2 min nasal breathing.

SESSION COMPLETE
Every pull creates posture.
Every rep creates shape.
Consistency builds physiques.
