UPPER BODY SCULPT B
Pull Priority - Phase 2 (Weeks 6 & 8)
Width • Detail • Density

SESSION TYPE
Hypertrophy • Density • Control

FOCUS
Upper Back Width
Lats
Shoulder Pop
Rear Delts
Triceps
Strong backs build strong physiques. Every pull should create shape, not just move weight.

TEMPO STRUCTURE
Lower → Bottom Pause → Lift → Top Pause
Default Tempo: 3-1-2-1

WARM UP
• Band Pull Apart x15
• Straight Arm Pulldown x12
• Face Pull x12

BLOCK A | PRIMARY COMPOUND PULL
A1. Wide Grip Lat Pulldown
3 x 8-10 (last set to FAIL)
Tempo 3-1-2-1
Rest 2 min
Cue
Pull elbows down to your ribs.
Chest up to the bar.
(Week 8 = Pull Up PR test instead - see PR Day notes)

BLOCK B | UPPER BACK DENSITY
B1. Seal Row or Chest Supported DB Row
2 x 8-10
Rest 90 sec
Cue
Drive elbows low.
Pause at the top.

B2. Half Kneeling Single Arm Lat Pulldown
2 x 10-12/arm
Rest 60 sec
Cue
Reach long at the top.
Pull elbow toward your hip.

BLOCK C | SHOULDER WIDTH
C1. Cable Lateral Raise (behind body)
2 x 10-12
Tempo 2-1-2-1

C2. Dumbbell Lateral Raise
2 x 10-12
↓ Drop weight
C3. Top Half Partials
x10-15 reps
Rest 90 sec
Cue
Lead with the elbow.
Keep constant tension.

BLOCK D | REAR DELT DETAIL
D1. Reverse Pec Deck Single Arm
2 x 12-15/arm
Rest 45 sec
Cue
Open through the elbows.
Don't shrug.

BLOCK E | TRICEPS SS
E1. Overhead Rope Extension
2 x 12-15
↓
E2. Single Arm Cable Kickback
2 x 12-15/arm
Rest 75 sec

BLOCK F | ABS
F1. Hanging Knee Raise
2 x technical failure
Rest 45 sec

COOL DOWN
2 min nasal breathing.

SESSION COMPLETE
Every pull creates posture.
Every rep creates shape.
Consistency builds physiques.
